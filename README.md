# 🤟 Silentvoice pro: Sign Language to Text/Speech Translator
> **Neutral Storm 2026- Future Tech (FT-04) AI-Powered Sign Language Recognition & Translation System**

---

## 📌 Project Overview
**SilentVoice Pro** is an innovative web-based application designed to bridge the communication gap between speech-impaired individuals and the general public. Built specifically for **Neural Storm 2026** under the **Human Impact / Future Tech** theme, the project leverages computer vision and speech synthesis to translate hand gestures into readable text and audible speech in real time.

## 🚀 Key Features
* **Real-Time Hand Tracking:** Powered by **MediaPipe Hands** for precise landmark detection and gesture classification.
* **Instant Text & Audio Conversion:** Converts recognized hand signs into text on screen and speaks them aloud using **gTTS (Google Text-to-Speech)**.
* **Lightweight & Accessible UI:** Clean, light-themed responsive interface built using pure HTML, CSS, and Vanilla JavaScript without heavy framework bloat.
* **Accessibility Focus:** Designed to empower speech-impaired individuals with an intuitive, seamless communication tool.

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Backend / AI Logic:** Python, OpenCV, MediaPipe
* **Speech Synthesis:** gTTS (Google Text-to-Speech)
